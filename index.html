อัปเดตอัตราดอกเบี้ย
วิธีติดตั้ง
  1. เปิด Google Sheets สร้างสเปรดชีตใหม่
  2. เปิด Extensions → Apps Script
  3. วางโค้ดจากไฟล์ Code.gs ที่ดาวน์โหลดไป
  4. บันทึก แล้วรัน initSheets() ครั้งแรกเพื่อสร้างชีท
  5. ไปที่ Deploy → New deployment → Web App
  6. ตั้ง Execute as: Me, Who has access: Anyone
  7. คัดลอก URL มาวางในช่อง GAS Web App URL ด้านบน
