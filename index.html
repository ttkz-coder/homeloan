อัปเดตอัตราดอกเบี้ย
วิธีติดตั้ง (คำแนะนำ)
  1. เปิด Google Sheets สร้างสเปรดชีตใหม่
  2. เปิดเมนู Extensions → Apps Script
  3. วางโค้ดจากไฟล์ Code.gs ที่ดาวน์โหลดไป
  4. บันทึก แล้วรันฟังก์ชัน initSheets() ครั้งแรกเพื่อสร้างโครงสร้างชีท
  5. ไปที่ปุ่มสีฟ้ามุมขวาบน Deploy → New deployment → Web App
  6. ตั้งค่า Execute as: Me และ Who has access: Anyone
  7. คัดลอก URL ที่ได้ มาวางในช่อง GAS Web App URL ด้านบน
